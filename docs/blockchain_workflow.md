# HoneyChain Blockchain Workflow

## 1. Purpose

Blockchain is used in HoneyChain to maintain a tamper-evident record of
important events in the honey supply chain.

Blockchain does not physically test honey or guarantee that the physical
product has not been replaced.

Laboratory testing verifies honey quality, while blockchain provides a
traceable record of authorized events.

---

## 2. Events Recorded

The following important events may be recorded:

- Harvest creation
- Batch creation
- Seal assignment
- Laboratory verification
- Processing
- Package creation
- Supply-chain handoff
