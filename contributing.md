# HoneyChain Contribution Guide

## 1. Branching

Do not directly develop on the `main` branch.

Each team member should create a separate branch.

| Member | Branch |
|---|---|
| Member 1 | `main` |
| Member 2 | `member2-iot` |
| Member 3 | `member3-ai` |
| Member 4 | `member4-blockchain` |
| Member 5 | `member5-backend` |
| Member 6 | `member6-frontend` |
